# 多指标组合策略说明文档

## 策略概述

**策略名称**: Multi-Indicator Combo Strategy (多指标组合策略)

**策略类型**: 趋势跟踪 + 反转策略

**风险等级**: 中等

**适用场景**:
- 寻找低波动率、趋势向上、处于超卖但多头格局的股票
- 适合中长期投资者
- 适合在市场调整后寻找反弹机会

---

## 策略逻辑

### 四大选股条件

| 条件 | 说明 | 参数 | 作用 |
|------|------|------|------|
| **1. 波动幅度控制** | 最近60天内波动幅度 ≤ 100% | period=60, threshold=100% | 过滤高波动股票，选择相对稳定的股票 |
| **2. BBI持续上升** | BBI多空指标连续N天上升 | rising_days=3 | 确保处于上升趋势 |
| **3. KDJ超卖** | 当前日J值 < -1 | threshold=-1 | 捕捉超卖反弹机会 |
| **4. MACD多头** | 当前日DIF > 0 | - | 确保处于多头市场 |

### 信号触发

**买入信号**: 当且仅当四个条件**同时满足**时产生买入信号

```
信号 = (波动幅度 ≤ 100%) AND (BBI持续上升) AND (J值 < -1) AND (DIF > 0)
```

---

## 指标说明

### 1. 波动幅度 (Volatility)

**计算公式**:
```
波动幅度 = (最近N天最高价 - 最近N天最低价) / 最近N天最低价 × 100%
```

**意义**:
- 衡量股票价格的波动程度
- 波动幅度小说明股票相对稳定
- 适合风险厌恶型投资者

### 2. BBI多空指标 (Bull and Bear Index)

**计算公式**:
```
BBI = (MA3 + MA6 + MA12 + MA24) / 4
```

**意义**:
- 综合多条均线的趋势指标
- BBI上升表示中期趋势向上
- 比单条均线更稳定

### 3. KDJ指标 (随机指标)

**计算公式**:
```
RSV = (收盘价 - N日最低价) / (N日最高价 - N日最低价) × 100
K = RSV的M1日移动平均
D = K的M2日移动平均
J = 3 × K - 2 × D
```

**J值的意义**:
- J值 < -1: 超卖状态，价格可能反弹
- J值 > 100: 超买状态，价格可能回调
- J值比K、D更敏感，能提前预警

### 4. MACD指标 (异同移动平均线)

**计算公式**:
```
DIF = EMA(12) - EMA(26)
DEA = EMA(DIF, 9)
MACD = (DIF - DEA) × 2
```

**DIF的意义**:
- DIF > 0: 多头市场，短期趋势强于长期
- DIF < 0: 空头市场，短期趋势弱于长期

---

## 策略优势

1. **多维度筛选**: 结合波动率、趋势、超卖三个维度
2. **风险控制**: 通过波动率条件过滤高风险股票
3. **趋势确认**: BBI上升和MACD多头双重确认
4. **抄底机会**: KDJ超卖条件捕捉短期反弹机会

---

## 策略局限

1. **信号较少**: 四个条件同时满足的概率较低
2. **滞后性**: BBI和MACD都是趋势指标，存在滞后
3. **震荡市表现差**: 在横盘震荡市场容易产生假信号
4. **需要足够数据**: 至少需要60天以上的历史数据

## 参数配置

### 默认参数

```yaml
multi_indicator_combo:
  enabled: true
  params:
    volatility_period: 60        # 波动率计算周期
    volatility_threshold: 100.0   # 波动幅度阈值(%)
    bbi_p1: 3                     # BBI第一条均线
    bbi_p2: 6                     # BBI第二条均线
    bbi_p3: 12                    # BBI第三条均线
    bbi_p4: 24                    # BBI第四条均线
    bbi_rising_days: 3            # BBI持续上升天数
    kdj_n_period: 9               # KDJ的N周期
    kdj_m1_period: 3              # KDJ的M1周期
    kdj_m2_period: 3              # KDJ的M2周期
    j_threshold: -1               # J值阈值
    macd_fast: 12                 # MACD快线
    macd_slow: 26                 # MACD慢线
    macd_signal: 9                # MACD信号线
    weight: 1.0                   # 信号权重
```

### 参数优化建议

| 参数 | 保守型 | 激进型 | 说明 |
|------|--------|--------|------|
| volatility_threshold | 80% | 120% | 越小越保守 |
| bbi_rising_days | 5 | 2 | 越长越确认趋势 |
| j_threshold | -5 | 0 | 越低超卖越深 |

## 使用方法

### 方式1: 通过配置文件启用

在 `strategies.yaml` 中设置:
```yaml
multi_indicator_combo:
  enabled: true
```

### 方式2: 运行测试脚本

```bash
# 测试单只股票
python test/test_multi_indicator_strategy.py --stock 000001.SZ

# 测试多只股票
python test/test_multi_indicator_strategy.py --stocks 000001.SZ,600519.SH

# 扫描整个数据库
python test/test_multi_indicator_strategy.py --test-all
```

### 方式3: 代码调用

```python
from strategies.multi_indicator_combo import MultiIndicatorComboStrategy

# 初始化策略
strategy = MultiIndicatorComboStrategy()

# 计算信号
signals = strategy.calculate(df)

# 获取最新信号
latest_signal = strategy.get_latest_signal(df)
```

## 配合其他策略

本策略可以与以下策略组合使用：

1. **均线多头排列**: 进一步确认趋势
2. **成交量放大**: 确认反弹有效性
3. **基本面筛选**: 优选业绩好的股票

---

## 风险提示

1. **历史表现不代表未来**: 回测结果仅供参考
2. **市场环境变化**: 策略在不同市场环境下表现差异很大
3. **严格执行止损**: 即使策略发出信号，也要设置止损
4. **仓位管理**: 不要满仓单一股票，分散投资
